# Telegram-бот OilanAI (@Oilan_aibot)

Второй клиент платформы: тот же «Дух Знаний» и сократовский метод, но в
Telegram. Реализован как serverless-функция Vercel `api/telegram.ts`
(эндпоинт `/api/telegram`).

## Что умеет

- `/start` — знакомство и выбор темы.
- Выбор темы → вопрос «что ты уже знаешь?» (барьер знаний) → сократовский диалог.
- `/done` — попросить итоговый разбор (рефлексия): три блока — «что понял сам»,
  «что нужно знать», «где застревал».
- `/new` (`/reset`) — начать новую тему.
- `/help` — справка.
- Мягкий анти-читинг: на «дай ответ / реши за меня» бот не выдаёт решение,
  а возвращает наводящий вопрос.

Диалог ведёт тот же Gemini, что и веб-прокси (`GEMINI_API_KEY`).

## Настройка (Vercel)

### 1. Переменные окружения

Vercel → проект → **Settings → Environment Variables**:

| Переменная | Значение | Обязательно |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) | да |
| `GEMINI_API_KEY` | ключ Gemini (уже есть у веб-прокси) | да |
| `GEMINI_MODEL` | напр. `gemini-2.5-flash` | нет |
| `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка | рекомендуется |

После добавления переменных сделай **Redeploy**, чтобы функция их увидела.

> ⚠️ **Никогда не коммить токен в репозиторий.** Он читается только из env.
> Если токен где-то засветился (например, в переписке) — выпусти новый через
> `/revoke` у @BotFather и обнови переменную на Vercel.

### 2. Проверка, что функция живёт

Открой в браузере:

```
https://<твой-домен>.vercel.app/api/telegram
```

Должен прийти JSON вида `{"ok":true,"configured":{"token":true,"gemini":true,...}}`.
Если `token`/`gemini` = `false` — переменные не заданы или не сделан redeploy.

### 3. Подключить вебхук

Один раз вызови Telegram API `setWebhook` (подставь свои значения). Удобно
прямо из браузера:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<твой-домен>.vercel.app/api/telegram&secret_token=<ТОТ_ЖЕ_СЕКРЕТ>
```

- `<ТОКЕН>` — `TELEGRAM_BOT_TOKEN`.
- `secret_token` — ровно та же строка, что в `TELEGRAM_WEBHOOK_SECRET`
  (если секрет не используешь — убери параметр `&secret_token=...`).

Ответ `{"ok":true,"result":true,"description":"Webhook was set"}` — готово.

Проверить статус вебхука:

```
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

### 4. Пользоваться

Открой бота `@Oilan_aibot` в Telegram и нажми **Start**.

## Заметки

- **Состояние диалога** хранится в памяти функции (`Map`) и сбрасывается при
  «холодном старте». Для демо этого достаточно. Для продакшена замени `sessions`
  на Vercel KV / Redis (хранить по `chat_id`).
- Функция всегда отвечает Telegram кодом `200`, чтобы не ловить повторные
  доставки одного апдейта.
- Лимит сообщения Telegram (4096 символов) обрабатывается автоматически —
  длинный разбор бьётся на части.
